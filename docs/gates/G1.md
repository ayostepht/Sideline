## Known issues carried forward

- **The worker CLI does not load `.env`.** Without `DEFAULT_LEAGUE_ID` in the environment, the league jobs are skipped with no log line saying why. Docker passes env through compose, so the container is unaffected. Follow-ups: log the skip reason (sleeper-data-engineer); decide whether local `pnpm run sync` should load `.env` (devops-engineer).
- A degraded nflverse run is stored as `skipped`, because there is no `degraded` status and no note column (backend-engineer, later phase).
- `docs/gates/*.json` include a local Chrome path with the OS user name. It is not a Sleeper identifier, but the gate should write home-relative paths (devops-engineer).
- Minor review items from Batches D, E and F, and the T1.5c and T1.7b follow-ups, are in the PROGRESS backlog.
