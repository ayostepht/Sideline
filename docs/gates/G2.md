## Human checkpoint

**How to run it (two terminals at the repo root):**
1. `pnpm dev:lan`. It prints `Open http://<ip>:3000 on your phone (same Wi-Fi)`. The first time, macOS asks whether node may accept incoming connections: click Allow (or System Settings, Network, Firewall).
2. `pnpm dev:worker`. It reads `.env` and uses `./data`.
3. Desktop: open http://localhost:3000. Phone: open the printed address on the same Wi-Fi.
4. To see first-run onboarding: `mkdir -p /tmp/sideline-try && cp data/sideline.sqlite /tmp/sideline-try/`, then run both commands with `SLEEPER_USERNAME= DEFAULT_LEAGUE_ID= DATA_DIR=/tmp/sideline-try` in front. The copy keeps the once-a-day player list guard, so it does not fetch it again.
