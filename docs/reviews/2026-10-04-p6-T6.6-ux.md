## A11y results

`pnpm test:a11y` could not target `127.0.0.1:3000` (occupied by the host's `dev:lan`, correctly left untouched per the brief). Ran instead against a `startStandaloneServer`-launched fixture server on a free port via `E2E_BASE_URL`, which only skips the main port-3000 webServer start -- the onboarding (3101) and auth (3102) sub-servers Playwright also needs still started normally since those ports were free.

**Result: 377 passed, 0 failed, 0 skipped** (list reporter, all 6 projects including the 3 chained not-found projects, which ran in full rather than being skipped, confirming no upstream failure this time). Note: this command's `--grep UI2` matches far more than UI2-tagged tests, because Playwright runs a dependency project's **entire** suite once any of its tests are selected (the `*-notfound` projects depend on the 3 main projects) -- this is the same already-documented `test:e2e`/`test:a11y` near-total-overlap quirk logged in `docs/PROGRESS.md`'s Phase 5 backlog, not new. The UI2 (axe) and UI5 (no 390px h-scroll) assertions specifically are a subset of this run and all passed, including every route this review screenshotted, both themes.

## What works well

- League's desktop-table + "You"-marker rollout (T6.3c) is genuinely complete and consistent across all 6 sections, in both card and table form -- this is exactly the kind of "same component, same job everywhere" consistency the checklist asks for.

- `/login` and the PWA/manifest/security-header work are clean, on-brand, and fully AA; no regressions found anywhere in this final sweep.
