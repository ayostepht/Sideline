# UX review: design system gallery (after Batch B)

Date: 2026-10-02 | Reviewer: ux-reviewer | Route: `/dev/gallery` (plus `?open=why`, `?open=sheet`, `?open=dialog`)

VERDICT: CHANGES REQUIRED. 0 Blocker, 2 Major, 7 Minor, 3 Nit. "Solid, calm foundation, but fix the sparkline and add the gallery overlays to axe before building pages on it."

**Privacy (ADR-009 item 17):** all four runs printed `screens: DATA_DIR <tmp>/sideline-seeded-... (seeded fixture)`. Screenshots stayed in `.screens/`. Only fake names appeared in the gallery.

**Screens reviewed:** 390, 768 and 1280 px, light and dark. Overlays viewed at 390 light only. `pnpm screens` accepts query-string routes, but the query is dropped from the output folder name, so the `?open=` variants overwrite each other (devops follow-up).

## Checks passed

- No horizontal scroll at 390 (verify with a `scrollWidth` test, since `overflow-x: hidden` could mask a bug).
- Touch targets at least 44 px on buttons, tabs, toggles and the sheet close button.
- Visible 2 px focus ring.
- Reduced-motion rule present.
- Semantic color is always paired with an icon or text.
- Position badges legible in both themes.
- Empty, error, stale and skeleton states exist.
- `pnpm test:a11y`: 12 passed (only `/`).

## Works well

ReasonChips and WhySheet (signed points with arrows, clean truncation), StaleBanner (one calm unit with a Sync action), StatCard hierarchy, overlay structure.

## Top 3 changes for look and feel

1. A legible Sparkline.
2. Clear affordance for ghost, link and disabled buttons.
3. Stronger dark-mode card and border contrast, with quieter accent-soft blocks.
