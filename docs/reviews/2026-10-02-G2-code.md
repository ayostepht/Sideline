## Major

**M1. Cross-origin writes are not blocked** (backend-engineer: `apps/web/lib/server/http.ts`, route handlers).
`/api/onboarding`, `/api/onboarding/league` and `/api/sync/run` read `request.text()` and `JSON.parse` it with no Content-Type or Origin check. A `text/plain` POST is a CORS simple request (no preflight), so any page open in a browser on the same network can swap the stored identity, wipe the active league, or queue syncs. `PATCH /api/settings` needs a preflight and is not affected. Docker binds 0.0.0.0 and auth is off by default; `dev:lan` exposes the same routes on the LAN.
Fix: require `Content-Type: application/json` on mutating routes (415 otherwise) and reject a present `Origin` whose host differs from `Host` (403), once in a shared helper, with unit tests.
Orchestrator check: confirmed in `apps/web/app/api/onboarding/route.ts`; no `middleware.ts` exists.
