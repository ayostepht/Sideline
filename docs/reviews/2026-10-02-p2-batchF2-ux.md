## Findings

| ID | Sev | Where | Problem | Fix | Status |
|---|---|---|---|---|---|
| m1 | Minor | `apps/web/app/not-found.tsx` via `components/empty-state.tsx` | The not-found page's only heading is an `<h2>` from `EmptyState`; no `<h1>` anywhere on the page. Doesn't trip axe (ruleset has no `page-has-heading-one`/`heading-order`), but breaks the one-h1-per-page convention every other page follows; screen-reader users jumping by heading level never hit a level-1 landmark. | Add an optional `level` prop to `EmptyState` (default 2), pass `level={1}` from `not-found.tsx`, or wrap with a visually-hidden `<h1>` ahead of it | Backlog |
| n1 | Nit | `sync-now-button.tsx` | `router.refresh()` 2s after "Sync started" could shift visible content if data changed materially; could not reliably trigger a live sync to observe directly. Code review already called for this exact behavior (m2); not a defect, a watch item. | None needed now | Backlog |
| n2 | Nit | not-found page | Zero app chrome on 404 (expected, safer than guessing leagueId context) means a deep-404'd user has only "Go home"/"Set up your league", no other nav. | Backlog idea: a minimal "back" link in a future revision | Backlog |

## A11y results

- `pnpm exec playwright test e2e/routes.spec.ts --grep "(settings|lineup|matchup|waivers|players|not-found route).*UI2"`: 36/36 passed (desktop-chromium, mobile-iphone, mobile-pixel; light + dark), zero serious/critical violations.
- Supplementary manual axe scan on team-detail not-found (`/league/teams/9999`, not yet in `e2e/routes.ts`'s `notFoundRoutes` list): 0 violations total, both themes. Confirmed real 404 status, confirmed dark-mode "Go home" button contrast 6.6:1 (well over AA's 4.5:1).

## What works well

- The four stub pages (Lineup/Matchup/Waivers/Players) share one `StubPage` component: consistent icon/heading/body/link pattern, 44px touch targets, correct active-nav highlighting in both the bottom tab bar and desktop sidebar.
- Settings cooldown copy change ("about a minute") doesn't wrap, truncate, or overflow at 390px in either theme.
- New loading.tsx skeletons for Settings/Lineup/Matchup/Players/Waivers all compose the same shared skeleton primitives already used by Home/League — structurally consistent, though not observed rendering live (reviewed via source; the fixture DB resolves too fast to reliably catch the transient state even with throttling).
- Dark-mode primary button token (`#818cf8` bg / `#0c0a09` text) is a deliberate accessible pairing, consistent across the not-found "Go home" button and Settings "Sync now".
